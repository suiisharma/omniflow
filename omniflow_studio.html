⚡ Auto-Start Server Whenever You Open HTML

OmniFlow v4.0 registers the custom Windows URL protocol omniflow://start and a Windows Logon background daemon in HKEY_CURRENT_USER. Once enabled, whenever you double-click omniflow_studio.html, the browser automatically fires omniflow://start and launches the Python background server silently!

Tip: Place OmniFlow_AutoStart.bat in the same folder as omniflow_engine.py and run it once (or run python omniflow_engine.py once). After that, opening omniflow_studio.html starts the server automatically every time!
